# 民用电缴费系统 — 系统概述

## 系统简介

民用电缴费系统（Residential Electricity Payment System）是一个基于 Web 的电力缴费管理平台，为居民和商业用电的抄表、计费、缴费、通知全流程提供信息化管理。

版本：v1.1.1

## 技术架构

- 后端语言：Java 24
- 后端框架：Spring Boot 3.4 + MyBatis-Plus 3.5.9
- 数据库：Oracle 23ai
- 前端框架：Vue 3 (Composition API) + Element Plus + ECharts
- 构建工具：Vite
- 安全：JWT 认证 + BCrypt 密码加密
- AI 大模型：Ollama + qwen2.5:3b（本地部署）
- 向量数据库：ChromaDB 1.5
- 嵌入模型：nomic-embed-text (768维)

## 核心功能模块

### 1. 用户管理
管理员可以新增、编辑、禁用、启用用户账户。三种角色：管理员(ADMIN)、收费员(COLLECTOR)、居民(RESIDENT)。支持手机号和邮箱格式校验，忘记密码自助重置。

### 2. 房产管理
管理房产信息（地址、面积、类型），支持住宅(RESIDENTIAL)和商业(COMMERCIAL)两种类型。每套房产关联一位业主。删除房产时级联删除所有关联数据。

### 3. 电表管理
电表与房产一对一绑定（一宅一表UNIQUE约束）。包括型号、安装日期、初始读数、状态管理（正常/故障/已拆）。删除电表时级联删除抄表记录、账单、缴费和告警。

### 4. 抄表管理
记录每日电表读数，通过存储过程 SP3 每日自动模拟智能电表抄表（含季节/周末/随机因子）。触发器 TR1 自动计算日用电量并检测读数倒转。

### 5. 账单管理
每月 1 日存储过程 SP1 自动生成上月账单。支持民用/商用双轨阶梯电价，按房产类型自动选择计价标准。账单含三档用电量和金额明细。

### 6. 缴费管理
支持在线缴费（居民自助）和线下缴费（收费员代收）。缴费金额自动锁定为应缴总额（本金+滞纳金）。缴费后触发器 TR3 自动更新账单状态并发送确认通知。

### 7. 通知系统
欠费提醒（触发器 TR2）、断电预警（存储过程 SP4）、缴费确认、异常告警、工单回复等通知自动生成和推送。

### 8. 告警系统
复合触发器 TR4b 检测用量异常（飙升>200%或骤降<50%历史均值），触发器 TR4a 检测抄表读数倒转。告警按级别（INFO/WARN/CRITICAL）分类管理。

### 9. 工单系统
居民可提交账单疑问、电表故障、投诉等工单。管理员和收费员在线回复，回复后提交人自动收到通知。

### 10. 电价配置
管理员可分别配置民用和商用的三档阶梯电价，支持修改档位用电量范围和单价。电价页面按民用/商用分表展示。

### 11. 仪表盘
ECharts 可视化仪表盘：环形饼图（账单状态分布）、柱状图（月度营收）、折线图（近6月用电趋势）、仪表盘（本月缴费率）。统计卡片展示用户/房产/账单/告警总数。

### 12. 智能客服
基于 RAG（检索增强生成）的 AI 客服，Ollama 本地 LLM + ChromaDB 向量检索。自动检测用户意图并预取个人账单/缴费数据，SSE 流式输出打字机效果。可拖动悬浮窗设计。

## 数据库设计

系统包含 11 张核心数据表：
- **SYS_USER**：系统用户（管理员/收费员/居民）
- **HOUSE**：房产信息（住宅/商业）
- **METER**：电表信息（一宅一表）
- **METER_READING**：每日抄表记录
- **PRICE_CONFIG**：电价配置（民用/商用双轨多版本）
- **BILL**：月度电费账单（含三档明细）
- **PAYMENT**：缴费记录（在线/线下）
- **NOTIFICATION**：系统通知（5种类型）
- **ALERT**：异常告警（飙升/骤降/倒转）
- **TICKET**：服务工单
- **TICKET_REPLY**：工单回复

配套 16 个触发器（11个自增 + 5个业务触发器，含 1 个复合触发器）、5 个存储过程、6 个业务视图，14个外键约束，22个CHECK约束，8个复合索引。

## 自定义主题

系统采用 Slate + Electric Cyan 色系，通过 CSS 变量覆写 Element Plus 默认蓝色主题。页面过渡动画：fade + slide 0.2s 平滑切换。全部使用 Element Plus Icons 矢量图标。
