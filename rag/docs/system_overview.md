# 民用电缴费系统 — 系统概述

## 系统简介

民用电缴费系统是一个基于 Web 的电力缴费管理平台，为居民用电的抄表、计费、缴费、通知全流程提供信息化管理。

## 技术架构

- 后端：Java 24 + Spring Boot 3.4 + MyBatis-Plus 3.5.9
- 数据库：Oracle 23ai
- 前端：Vue 3 + Element Plus + Vite
- 安全：JWT 认证 + BCrypt 密码加密
- 智能客服：Ollama + ChromaDB + RAG

## 核心功能模块

### 1. 用户管理
管理员可以新增、编辑、禁用、启用用户账户。系统支持三种角色：管理员、收费员、居民。

### 2. 房产管理
管理居民房产信息，每套房产关联一位用户。一宅一表原则。

### 3. 电表管理
管理电能表信息，包括型号、安装日期、读数、状态。电表与房产一对一绑定。

### 4. 抄表管理
记录每日电表读数，自动计算日用电量。系统每日模拟智能电表自动抄表。

### 5. 账单管理
每月 1 日自动生成上月账单，按阶梯电价计算。账单包含各档用电明细和总金额。

### 6. 缴费管理
支持在线缴费和线下柜台缴费。缴费后自动更新账单状态。每天计算滞纳金。

### 7. 通知系统
欠费提醒、断电预警等通知自动推送给相关用户。点击通知自动标记已读。

### 8. 告警系统
用电量异常（飙升/骤降）、抄表读数倒转等异常自动检测和告警。

### 9. 工单系统
居民可提交账单疑问、电表故障、投诉等工单。管理员和收费员在线回复。

### 10. 电价配置
管理员可配置阶梯电价参数，支持三档定价。

### 11. 智能客服
基于 RAG（检索增强生成）的 AI 客服，可回答业务问题并查询用户个人数据。

## 数据库设计

系统包含 11 张核心数据表：
- SYS_USER：系统用户
- HOUSE：房产信息
- METER：电表信息
- METER_READING：抄表记录
- BILL：账单
- PAYMENT：缴费记录
- NOTIFICATION：通知
- ALERT：告警
- TICKET：工单
- TICKET_REPLY：工单回复
- PRICE_CONFIG：电价配置

配套 4 个业务触发器、4 个存储过程、6 个业务视图，完整实现业务逻辑在数据库层的封装。
