# 民用电缴费系统 — 使用指南

## 如何登录系统

1. 打开浏览器，访问系统地址（默认 http://localhost:5173）
2. 输入用户名和密码
3. 点击"登录"按钮

## 如何查看电费账单

### 居民
1. 登录后进入"我的账单"页面
2. 可以看到所有月份的账单列表
3. 账单包含：月份、用电量、各档费用明细、总金额、滞纳金、状态
4. 点击某条账单可查看详细信息

### 管理员/收费员
1. 进入"账单查询"页面
2. 可以查看所有用户的账单
3. 支持按月份筛选

## 如何在线缴费

1. 登录居民账号
2. 进入"我的账单"页面
3. 找到状态为"PENDING"（待缴）或"OVERDUE"（逾期）的账单
4. 点击"缴费"按钮
5. 确认金额后完成支付
6. 缴费后账单状态变为"PAID"（已缴）

## 如何查看缴费记录

1. 居民：在"我的缴费"页面查看历史缴费记录
2. 管理员/收费员：在"缴费记录"页面查看所有缴费

## 如何提交工单

1. 居民登录后在"我的工单"页面点击"提交工单"
2. 选择工单类型：账单疑问、电表故障、投诉、其他
3. 填写详细描述
4. 提交后管理员或收费员会回复
5. 点击工单可查看回复

## 如何查看通知

1. 登录后，顶部栏右上角有通知铃铛图标
2. 红色数字表示未读通知数
3. 点击铃铛进入"我的通知"页面
4. 点击某条通知自动标记为已读

## 忘记密码怎么办

联系管理员，管理员在"用户管理"页面可以一键重置密码为默认值 123456。

## 如何联系客服

页面右下角有智能客服悬浮按钮，点击即可与 AI 客服对话。可以询问：
- 账单问题
- 电价政策
- 使用帮助
- 系统功能说明

如果 AI 客服无法解决，可到"我的工单"提交人工工单。
