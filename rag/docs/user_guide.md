# 民用电缴费系统 — 使用指南

## 如何登录系统

1. 打开浏览器，访问系统地址（默认 http://localhost:5173）
2. 输入用户名和密码
3. 点击"登录"按钮

## 如何查看电费账单

### 居民
1. 登录后进入"我的账单"页面
2. 可以看到所有房产的账单列表
3. 账单包含：账期、用电量、各档费用明细（1/2/3档）、总金额、滞纳金、状态
4. 一个用户可能有多套房产，每套房产每月各一张账单

### 管理员/收费员
1. 进入"账单查询"页面
2. 可以查看所有用户的账单
3. 支持按状态和月份筛选

## 如何在线缴费

1. 登录居民账号
2. 进入"我的账单"页面
3. 找到状态为"待缴"(PENDING) 或"逾期"(OVERDUE) 的账单
4. 点击"缴费"按钮
5. 确认金额（含滞纳金，如有）后完成支付
6. 缴费后账单状态变为"已缴"(PAID)

## 如何查看缴费记录

1. 居民：在"我的缴费"页面查看历史缴费记录
2. 管理员/收费员：在"缴费记录"页面查看所有缴费，支持按渠道筛选（在线/线下）

## 如何提交工单

1. 居民登录后在"我的工单"页面点击"提交工单"
2. 选择工单类型：账单疑问、电表故障、投诉、其他
3. 填写标题和详细描述
4. 提交后管理员或收费员会回复
5. 点击工单可查看回复内容

## 如何查看通知

1. 登录后，侧边栏顶部有通知入口
2. 未读通知会显示在"我的通知"页面
3. 点击某条通知可查看详情并自动标记已读
4. 通知类型包括：欠费提醒、缴费确认、断电预警、异常告警、工单回复

## 忘记密码怎么办

1. 在登录页面点击"忘记密码"
2. 输入用户名和注册时填写的手机号或邮箱进行身份验证
3. 验证通过后可直接设置新密码

## 如何使用智能客服

页面右下角有智能客服悬浮按钮（仅居民端可见），可拖拽移动。点击即可打开对话面板与 AI 客服对话。可以询问：
- 我的电费多少钱？（支持按月份查询，如"上个月电费多少钱"）
- 电价怎么算的？
- 怎么在线缴费？
- 如何提交工单？
- 其他系统和政策相关问题

如果 AI 客服无法解决，可到"我的工单"提交人工工单。

## 电价说明

系统支持民用和商用两种电价标准：
- **民用住宅**：0-200度 0.50元/度, 201-400度 0.55元/度, 400度以上 0.80元/度
- **商业用电**：0-500度 0.78元/度, 501-1000度 0.95元/度, 1000度以上 1.25元/度

系统会根据房产类型自动选择对应的电价标准。
